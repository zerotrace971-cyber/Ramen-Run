# 90-second demo video script

## 0:00–0:15 — Hook

Open the landing page on desktop. Say: “Suzume’s Stellar Ramen Run is a full end-to-end Stellar dApp with an actual comic courier game where players sponsor cosmic ramen routes and earn on-chain stamps.” Click **Start the story** and move through the comic panels.

## 0:15–0:35 — Playable game

Launch Meteor Miso. Use the keyboard or on-screen controls to move Suzume across lanes. Collect stardust and ramen, dodge an asteroid, activate Boost, then show the score/combo/hearts changing. Finish the short run and show its completion receipt.

## 0:35–0:48 — Characters and responsive product

Open Character Challenges. Accept a quest from Yori or Mika, then switch browser responsive mode to a phone-sized width. Point out the mobile controls, mobile drawer, readable quest cards and persistent Suzume chat.

## 0:48–1:05 — On-chain flow

Connect Freighter. Sponsor **Meteor Miso**. Show the signing/loading state then the success receipt with the actual testnet transaction hash. Say: “The client simulates `fund_route`, Freighter signs the XDR locally, and Soroban submits it.”

## 1:05–1:18 — Advanced contracts

Open Stamp Vault and How It Works. Say: “The Vault records the route, then on completion delegates only one nested authorization to the Stamp Shelf. The shelf requires the Vault’s contract authorization before minting.”

## 1:18–1:28 — Real-time and AI

Open Live Dispatch. Show the event feed refreshing. Ask Suzume “How are stamps safe?” and show her answer.

## 1:28–1:40 — Proof

Show `npm run test`, `cargo test --workspace`, and the green GitHub Actions workflow. End on the README deployment section and live demo URL.
