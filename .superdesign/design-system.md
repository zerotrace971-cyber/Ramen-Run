# Suzume’s Stellar Ramen Run design system

Build an internal manga-ops console that belongs inside the existing dApp. Preserve the dark indigo shell, cyan system labels, gold action accents, pink alert accents, Bricolage Grotesque heading typography, Space Mono technical labels, thin translucent borders and gently asymmetric comic corners. This is an administrator tool, not a player arcade screen: favor dense, legible operational tables, protected-access states, clear timestamps and compact audit rows. Make mobile collapse safely into cards without hiding security status.

Use only: ink `#080717`, ink-2 `#111027`, ink-3 `#1b1938`, paper `#f7f5f0`, muted `#9d9ab5`, cyan `#5ae5e1`, pink `#ff5e9e`, gold `#ffc95b`, purple `#9a76ff`; fonts Bricolage Grotesque, Space Mono and DM Mono. Keep the application’s 230px sidebar and 72px topbar visual language.
