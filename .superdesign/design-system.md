# Suzume’s Stellar Ramen Run design system

Build a lively Japanese neon-manga arcade inside the existing Stellar dApp. Preserve the dark indigo application shell, cyan system labels, gold action accents, pink danger accents, purple depth, Bricolage Grotesque display typography, Space Mono technical labels, thin luminous borders, and asymmetric comic-panel corners.

The Jetpack game should feel like a premium arcade cabinet rather than an operations dashboard. Prioritize an immediately readable playfield, route-progress drama, tactile controls, strong collision/reward feedback, visible short-term objectives, and responsive mobile controls. Keep the rooftop Testnet shop visually secondary to the game and make purchases clearly distinct from earned in-run bonuses.

Use only: ink `#080717`, ink-2 `#111027`, ink-3 `#1b1938`, paper `#f7f5f0`, muted `#9d9ab5`, cyan `#5ae5e1`, pink `#ff5e9e`, gold `#ffc95b`, purple `#9a76ff`; fonts Bricolage Grotesque, Space Mono and DM Mono. Preserve the 230px sidebar and 72px topbar language when the full shell is shown.
